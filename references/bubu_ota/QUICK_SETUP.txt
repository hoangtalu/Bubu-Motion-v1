📋 USEFUL COMMANDS:

   chat key <KEY>       Set API key
   chat status          Show configuration
   chat voice Aoede     Change voice (Aoede/Charon/Fenrir/Kore/Puck)
   chat audio on        Enable audio mode
   chat on              Enable chat system

   demo-setup           Create test reminders/notes
   demo-chime           Test reminder sound

🆘 TROUBLESHOOTING:

   Chat not working?
   → Run: chat status
   → Check: key=(set) not key=(not set)
   → Fix: chat key YOUR_KEY

   GitHub secret warning?
   → You're using old firmware
   → Rebuild with latest code

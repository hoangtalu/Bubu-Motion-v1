📝 BASIC USAGE

  #include "display_system.h"

  // Trigger emotion (duration in milliseconds)
  DisplaySystem_triggerLegacyEmotion(LEGACY_EMO_LOVE, 8000);

  // Check if playing
  if (DisplaySystem_isLegacyEmotionActive()) {
    // emotion is animating...
  }

  ★ ★ ★  INTEGRATED INTO EYE TAP GESTURE!  ★ ★ ★

  Just upload and tap on the eyes to cycle through emotions:

    👆 Tap 1: LOVE emotion    (heart eyes + blush)
    👆 Tap 2: CYCLOP emotion  (giant eye)
    👆 Tap 3: DRUNK emotion   (whirlpool eyes)
    👆 Tap 4: LOVE again      (cycles)

  Each emotion lasts 8 seconds, then returns to normal eyes.

  ──────────────────────────────────────────────────────────────────

  Alternative: Auto-cycle test (without tapping)

  1. Copy testLegacyEmotions() from TEST_LEGACY_EMOTIONS.cpp
  2. Add to main.cpp:
       void testLegacyEmotions();  // after includes
       testLegacyEmotions();        // end of loop()
  3. Upload and watch emotions cycle every 10 seconds

  • Duration is in MILLISECONDS (8000 = 8 seconds)
  • System auto-initialized in DisplaySystem_begin()
